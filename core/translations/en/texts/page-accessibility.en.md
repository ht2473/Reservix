## Measures taken

* All actions are available from the keyboard; the tab order follows the visual
  order of elements, and the visible focus is never suppressed.
* Every page has a top-level heading and breadcrumbs, and a "skip to content"
  link at the start of the document.
* Form errors are linked to fields programmatically: a screen reader reads the
  reason together with the field name, not separately.
* Element states are expressed in markup, not only by color: the active menu
  item is marked with an attribute, and signal values come with a label.
* Text and control contrast meets the AA level.
* Feedback forms are protected from automated submissions by a hidden field and
  a fill-time check, without image challenges that are inaccessible to people
  with visual impairments.

## Limitations

The performance–potential matrix and competency radar charts present data
graphically. Tabular versions of the same information are available via a link
next to each chart.

## Feedback

If any part of the interface turns out to be inaccessible, please let us know
through the feedback form: such requests are handled first.
