{% blocktranslate %} Индекс готовности сводит разнородные показатели резервиста к одному числу по шкале от нуля до ста. Он нужен там, где требуется сравнение: выбрать преемника из пяти кандидатов, опираясь на пять разных наборов оценок, человек не может — а сравнить пять чисел может. {% endblocktranslate %}

{% blocktranslate %} Число при этом никогда не предъявляется без разбора. Индекс, который нельзя разложить на составляющие, невозможно ни оспорить на кадровой комиссии, ни превратить в план развития, и в кадровом решении он бесполезен. {% endblocktranslate %}

{# ==== Оговорки ======================================================= #}

{% translate "Чего индекс не делает" %}

  • {% blocktranslate %} Не принимает решение. Индекс упорядочивает кандидатов и объясняет порядок; назначает человека человек. {% endblocktranslate %}
  • {% blocktranslate %} Не заменяет полноту оценки. Необеспеченный данными критерий исключается из свёртки, а его вес распределяется между остальными. Доля обеспеченного веса хранится вместе с индексом и выводится рядом с ним: иначе рейтинг поощрял бы неполноту оценки. {% endblocktranslate %}
  • {% blocktranslate %} Не сравнивает несравнимое. Значение индекса осмысленно относительно конкретной целевой должности: тот же работник получит другой индекс по отношению к другой должности. {% endblocktranslate %}
