# Учётные данные демонстрационного стенда

Документ содержит перечень учётных записей, создаваемых командой
`python manage.py seed_users`.

**Пароль всех записей:** `Reserv-Demo-2026!`

Пароль единый намеренно: на демонстрационном стенде можно войти под любой
ролью, не запрашивая доступ. В рабочей системе учётные записи создаёт
администратор, пароль выдаётся одноразовым и подлежит обязательной смене при
первом входе — механизм реализован и проверяется тестами.

---

## Роли и области видимости

Права в системе двумерны и назначаются независимо.

* **Роль** определяет набор доступных операций.
* **Область видимости** определяет круг сотрудников, чьи данные доступны.

Два пользователя с одинаковой ролью могут видеть разный объём данных — именно
это разграничение и демонстрируют учётные записи ниже.

| Область видимости | Что доступно |
|---|---|
| Вся организация | Данные всех сотрудников всех филиалов |
| Филиал | Сотрудники одного филиала |
| Подразделение | Сотрудники одного подразделения |
| Непосредственные подчинённые | Подразделение пользователя и все вложенные в него |
| Только свои данные | Собственная карточка сотрудника |

1. Войдите под `maria.ivanova@meridian-soft.ru` — в списке сотрудников

2. Войдите под `alexey.sidorov@meridian-soft.ru` — при той же роли список
   ограничен филиалом Санкт-Петербург.
3. Войдите под `dmitry.petrov@meridian-soft.ru` — видны четыре вложенных
   отдела департамента разработки.
4. Войдите под `elena.orlova@meridian-soft.ru` — виден только отдел серверной
   разработки, вложенный в тот же департамент.
5. Войдите под `igor.smirnov@meridian-soft.ru` — доступна только собственная
   карточка; попытка открыть чужую даёт отказ с кодом 403.
6. Войдите под `admin@meridian-soft.ru` и откройте журнал аудита — все
   перечисленные входы, включая неудачные попытки, зафиксированы.

## Восстановление стенда

```bash
uv run python manage.py seed_org --flush
uv run python manage.py seed_users --flush
```

Флаг `--flush` удаляет существующие записи перед созданием. Без него команды
обновляют записи по коду и адресу электронной почты, сохраняя связанные
данные.

Пароль можно задать явно:

```bash
uv run python manage.py seed_users --password "Drugoy-Parol-2026!"
```
